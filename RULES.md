# Project Rules

These rules apply to all work on this codebase and must always be followed.

## Rule 1 — No emojis

Never use emojis in UI copy, code, or content. Where an emoji might otherwise
be used (e.g. as a visual marker, status indicator, or decorative icon),
render a new inline SVG icon instead, matching the style of existing icons in
the codebase (e.g. `viewBox="0 0 24 24" fill="none" stroke="currentColor"
strokeWidth="1.75" strokeLinecap="round" strokeLinejoin="round"`).
